# Goat RFID-Based Farm Management System

## Project Description
A web-based application developed to manage goat farm activities using RFID technology. It helps farmers maintain goat records, health details, breeding information, and farm management data.

## Features
- Goat registration using RFID.
- Baby goat registration.
- Health and vaccination record management.
- Breeding management.
- Farm owner and veterinary details.
- Feed cost calculation.
- Livestock record filtering and CSV export.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python Flask
- **Database:** SQLite
- **Hardware:** RFID reader and RFID tags

## Installation and Execution

1. Clone or download the project.
2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   python app.py
   ```

4. Open your browser and visit:

   `http://127.0.0.1:5000`

## Conclusion
This project simplifies goat farm management by digitizing livestock records and supporting RFID-based goat identification.
